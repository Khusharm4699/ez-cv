# Critical Rules — Accuracy & Anti-Fabrication

These rules override style. A resume that overclaims fails the interview it wins.

## Provenance (every claim is tagged)

- `verified` — stated by the owner or present in their source material. Use freely.
- `estimate` — a defensible approximation. MUST be written with a `~` (e.g.
  `~60% faster`) and confirmed with the owner before sending.
- `placeholder` — unknown. Surface it loudly until the owner fills it in.

## Verb discipline (don't inflate the role)

| If the owner... | Use | Don't use |
|---|---|---|
| designed + shipped it | Built, Architected, Shipped, Engineered | — |
| improved an existing thing | Optimized, Improved, Extended, Refactored | Built, Created |
| was one of several | Contributed to, Co-built | Led, Owned (unless true) |
| only investigated | Analyzed, Triaged, Diagnosed | Fixed (unless they fixed it) |

## No fabrication

- Never invent a number to fill a gap. If a metric is unknown, ask or mark `estimate`.
- Never claim a tool/framework the owner has not used. Missing JD skills -> gap
  plan, not the resume.
- Never upgrade "helped with" into "led".
- Keep titles, companies, and dates exact. Copy them verbatim from source material.
